# Milestone 2 Status

## Features Implemented

I created a working login authentication program based on my Milestone 1 design. The program asks the user to enter a username and password, checks the information against stored login values, and displays whether the login was successful. It also counts failed login attempts and locks the account after three incorrect attempts.

## Future Improvements

In future milestones, I plan to add multiple user accounts, stronger password requirements, and a way to reset a locked account. I may also improve the messages shown to the user and hide the password while it is being entered.

## Issues or Questions

The main issue I encountered was making sure the functions and loop were indented correctly. I also had to make sure I ran the Python file from the correct project folder. After fixing those issues, the program worked as expected.
